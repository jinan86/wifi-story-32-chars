Entry for the [make.fun](https://make.fun/c/u-xvader-tell-a-whole-story-in-32-characters-f86dd978) competition **Tell a Whole Story in 32 Characters**.

## The entry

```
Millionaire. Still Steals WiFi
```

30 characters. One Wi-Fi network name that lands a joke and implies a
whole story: a millionaire — a character with money — is still stealing
the neighbour's Wi-Fi. Situation, character, and something that
happened, in the few words a stranger sees in a phone's network list.

## How it works

`main.py` (stdlib only, deterministic, no network) writes the fixed
name to `/output/entry.txt` (or a path given as the first argument):

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py out.txt    # writes out.txt
```
